# Fiber Academy · Trainee prototype

Open `index.html` in Chrome or Edge — no server needed.

## Sharing review comments (no hosting)
Comments are saved in your browser. To share them:

1. **Comments** (bottom bar) → **Download comments** → a file like `fiber-feedback_client-a_2026-11-13.json` is saved.
2. Send the file to the next reviewer (Teams / email).
3. They open the prototype → **Comments** → **Import comments** (or drag the file onto the panel). You can pick several files at once.

Imports **merge**: new comments are added, edited/resolved ones keep the newest version, duplicates are ignored — importing the same file twice is safe.
**CSV (Excel)** exports a readable list; **Clear all** removes comments from this browser only (download first).
